## ✨ О проекте

Многие дети сталкиваются со сложностями при входе в свою учётную запись Minecraft: забывают регистр букв, путают символы или теряются при скрытом вводе пароля.

**Тренажёр логина и пароля в стиле Minecraft** превращает рутинный процесс запоминания пароля в увлекательный квест:
- Ребёнок тренируется вводить логин и пароль в знакомом интерфейсе любимой игры.
- Пароль по умолчанию **открыт**, чтобы ребёнок видел свои действия и вырабатывал механическую память пальцев.
- За каждый правильный ввод открывается новый персонаж без повторов.
- Сбор всех 15 мобов открывает грандиозный **Суперприз** с Драконом Края, победной фанфарой и Золотым Кубком Знатока!

## 🚀 Ключевые возможности

1. **📦 Полная автономность (Zero Dependencies)**:
   - Вся программа скомпилирована в один файл размером **~1 МБ**.
   - Все 15 изображений персонажей, спрайт Дракона Края, звуки и иконка зашиты прямо внутрь бинарного файла.
   - Не требуется установка Python, Java, .NET Framework или библиотек.

2. **🌍 Мультиязычность в 1 клик (RU / EN / PL)**:
   - Поддерживаются три языка: **Русский** 🇷🇺, **English** 🇬🇧 и **Polski** 🇵🇱.
   - Переключение на лету прямо в окне приложения через кнопки в шапке `[ RU ] [ EN ] [ PL ]`.
   - Полный перевод всего интерфейса, подсказок, системных сообщений, экрана суперприза и описаний мобов.

3. **👁️ Открытый пароль по умолчанию**:
   - Пароль сразу отображается обычным текстом, что критически важно на этапе обучения.
   - В любой момент доступна кнопка-глазок `[ 👁 ]` / `[ 🔒 ]`, позволяющая скрыть символы точками или вернуть их показ.

4. **🎯 Крупный детский интерфейс (друг под другом)**:
   - Элементы увеличены в 1.5 раза для удобства детских глаз.
   - Фокус ввода при старте сразу стоит в поле логина.
   - Клавиша `Enter` плавно перемещает курсор из логина в пароль и отправляет форму.

5. **⭐ Коллекция из 15 мобов с гарантированным прогрессом**:
   - Алгоритм исключает повторы: каждая успешная попытка открывает случайного персонажа из числа ещё не собранных.
   - Наглядный счётчик прогресса: *«⭐ Открыто персонажей: 7 из 15 (Осталось: 8)»*.

6. **🏆 Грандиозный Суперприз**:
   - При сборе всех 15 персонажей активируется триумфальный экран:
     - Золотой праздничный баннер.
     - Арт **Дракона Края** в лучах магии Края.
     - Достижение: *«[ ЛЕГЕНДАРНЫЙ МАСТЕР MINECRAFT ]»*.
     - Награда: *«🥇 Золотой Кубок Знатока Minecraft!»*.
     - Торжественная победная фанфара.
     - Кнопка быстрого сброса для повторного прохождения квеста.

7. **🎵 Звуковое сопровождение**:
   - Звук повышения уровня опыта (XP level-up) при успехе.
   - Торжественная оркестровая фанфара победы при завершении коллекции.
   - Мягкий предупреждающий звук при ошибке с подсветкой подсказки.

## ⚙️ Настройка приложения

### Параметры конфигурации

| Параметр | Значения | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `login` | Любая строка | `steve` | Правильный логин игрока для проверки |
| `password` | Любая строка | `diamond` | Правильный пароль игрока для проверки |
| `language` | `ru`, `en`, `pl` | `ru` | Язык интерфейса приложения |
| `show_password` | `1` или `0` | `1` | `1` — пароль открыт по умолчанию, `0` — скрыт точками |
| `show_hint` | `1` или `0` | `1` | `1` — показывать подсказку внизу экрана, `0` — скрыть |

---

### Для Windows (`config.ini`)

Рядом с файлом `MinecraftPasswordTrainer.exe` находится текстовый файл `config.ini`:

```ini
[Credentials]
; Укажите настоящий логин и пароль ребёнка:
login = steve
password = diamond

[Options]
; Язык интерфейса: ru (Русский), en (English), pl (Polski)
language = ru
; 1 = показывать пароль открытым текстом по умолчанию, 0 = скрывать точками
show_password = 1
; 1 = показывать подсказку внизу экрана для тренировки, 0 = скрыть
show_hint = 1
```

> [!TIP]
> Файл `config.ini` можно редактировать в обычном Блокноте даже во время работы программы — новые настройки подхватываются на лету!

---

### Для веб-версии (в браузере)

1. Нажмите на кнопку **`[ ⚙️ Настройки ]`** в правом верхнем углу страницы.
2. В появившемся окне задайте логин, пароль, язык и параметры отображения.
3. Нажмите **`💾 СОХРАНИТЬ`**. Данные сохранятся в памяти браузера (`localStorage`).

> [!NOTE]
> При запуске через `python3 app.py` изменения в браузере автоматически сохраняются обратно в файл `config.ini`.

## 🔒 Безопасность и Windows SmartScreen

### 1. Предостережение по хранению паролей
> [!CAUTION]
> **Не используйте реальные секретные мастер-пароли!**  
> Настройки сохраняются на вашем устройстве в открытом (незашифрованном) виде: в файле `config.ini` для Windows и в `localStorage` для веб-версии, чтобы родители могли легко настроить программу без специальных навыков.  
> **Рекомендация:** Используйте тренировочный пароль или пароль исключительно от локального игрового профиля/лаунчера. Ни в коем случае не вводите пароль от родительской почты, учётной записи Microsoft/Xbox с привязанными банковскими картами или пароли от банковских систем!

### 2. Предупреждения Windows SmartScreen и антивирусов (False Positives)
Поскольку тренажёр является бесплатным открытым пет-проектом, скомпилированный файл `MinecraftPasswordTrainer.exe` не имеет дорогостоящей коммерческой цифровой подписи (EV Code Signing Certificate).

Из-за того, что бинарник скомпилирован через кросс-компилятор Zig и содержит поля ввода логина и пароля, эвристические анализаторы **Windows Defender SmartScreen** или антивирусы могут ошибочно выдать предупреждение о неизвестном издателе или заподозрить кейлоггер/фишинг.

**Как запустить программу в Windows:**
1. При появлении синего экрана *«Система Windows защитила ваш компьютер»* (SmartScreen):
2. Нажмите текстовую ссылку **«Подробнее»** (*More info*).
3. Нажмите появившуюся кнопку **«Выполнить в любом случае»** (*Run anyway*).
4. *(Альтернатива)* Вы можете играть прямо в браузере через [GitHub Pages](https://dzuyonak.github.io/password-trainer-minecraft/) либо скомпилировать исполняемый файл самостоятельно из исходного кода (`./build.sh`).

## 🛠️ Сборка из исходников

Для кросс-компиляции исполняемого файла Windows PE32+ используется компилятор **Zig** (поддерживает компиляцию под Windows прямо с macOS, Linux или Windows без Wine и MSVC):

### 1. Быстрая сборка через скрипт:
```bash
./build.sh
```

### 2. Сборка вручную:
```bash
# 1. Генерация заголовочного файла ресурсов:
python3 generate_assets.py

# 2. Компиляция нативного Windows бинарника:
zig c++ -target x86_64-windows-gnu \
  -Wl,--subsystem,windows \
  -O2 \
  main.cpp \
  -lgdiplus -lole32 -lwinmm -luser32 -lgdi32 -lcomctl32 -lshlwapi \
  -o MinecraftPasswordTrainer.exe
```

## ☁️ CI/CD и GitHub Pages

1. **Автоматическая сборка в облаке (GitHub Actions)**:
   При каждом коммите или пуше в ветку `main` запускается рабочий процесс [.github/workflows/build.yml](.github/workflows/build.yml). Он собирает свежий бинарник `MinecraftPasswordTrainer.exe` и прикрепляет его в артефакты сборки.

2. **Хостинг онлайн-версии (GitHub Pages)**:
   - В настройках репозитория откройте **Settings** ➔ **Pages**.
   - В выпадающем меню **Branch** выберите ветку `main` и папку `/(root)`.
   - Нажмите **Save**.
   - Тренажёр станет доступен онлайн по ссылке: `https://dzuyonak.github.io/password-trainer-minecraft/`.
